# Tourenbibliothek Allgaeu

Wander-, Berg-, Ski- und Radziele in Tagesreichweite ab Unterthingau, filterbar nach Zeitbudget, Hoehenmetern, Anfahrt und Anspruch. Jede Kennzahl stammt aus der jeweils verlinkten Quelle.

Die Seite laesst sich auf den Startbildschirm legen und funktioniert danach auch ohne Netz.
